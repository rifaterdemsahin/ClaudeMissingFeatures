🏛️ Architecture

The rule: your MacBook Pro does the heavy work with local libraries; Claude only makes judgement calls from a one-page text report. That keeps token use low, makes every step repeatable by you, and keeps video and private screens off the cloud.

Token rules

  1. Never ask Claude to look at frames to find something. OCR finds text and positions locally; Claude reads the text result. Look at a still only to confirm a final look (a few per video).
  2. Read one summary, not many outputs. REPORT.md is the single hand-off: offsets and confidence, cut candidates, personal windows with what is said, edit counts, export privacy result.
  3. Verify with a script. verify_export.py OCRs the finished export and lists any sensitive text still visible (pass or fail), instead of Claude re-viewing the video.
  4. Batch and background. Run long jobs (Whisper, OCR, render) in the background with a single wait; do not poll every minute. Remotion's first ETA is wrong, measure frames per 30 s.
  5. Pull, do not rediscover. The kit on Drive carries the scripts and the spec, so no re-deriving or re-explaining.
  6. Filter outputs. Print counts and the first lines (head, jq), not whole files.

Run it yourself

scripts/pull_kit.sh ~/projects/<new>                     # kit from Drive (id from Key Vault)
cd ~/projects/<new> && ./new-video.sh "<Title>" <seconds>
scripts/pipeline.sh "~/Downloads/<folder>" <slug>           # sync, base video, subtitles, OCR, report (local)
cat REPORT.md                                               # the one page Claude (or you) reads
# edit remotion/src/overlays.json (slides, speedups) and cuts.json, then:
python3 -I scripts/build_blurs.py                           # blur boxes from OCR
cd remotion && npm install && npm run studio                # http://localhost:3000/LongForm
npm run render                                              # export (about 2x video length at 13 fps)
cd .. && python3 -I scripts/verify_export.py                # privacy check, pass/fail
scripts/serve.sh                                            # player: Original vs Latest export
